WEB DEVELOPMENT DAY 01

Getting Started with Web Development

Every website begins with a few simple building blocks.

My web development journey began with understanding how websites work and how browsers display information. I started exploring Visual Studio Code, creating HTML files, and opening my work in a browser.

One important lesson was understanding the role of HTML, CSS, and JavaScript. HTML provides the structure, CSS controls the appearance, and JavaScript can add dynamic behaviour. These technologies work together to create the websites we use every day.

I'm learning that the best way to understand a concept is to practise it, test the result, and fix mistakes instead of being afraid of them.

HTML & CSS DAY 02

Building My First Personal Webpage

Turning basic HTML into a page that feels like my own.

My next step was creating a personal introduction page. I used headings, paragraphs, links, and lists to organise information about myself, my education, and the technologies I want to learn.

CSS made the page more engaging through colours, spacing, typography, and layout. I also learned why linking a separate stylesheet is helpful: it keeps the HTML organised and makes design changes easier to maintain.

I discovered that even small mistakes, such as a missing stylesheet link or an incorrect filename, can affect the entire appearance of a webpage. Checking file paths carefully is an important habit.

PORTFOLIO PROJECT DAY 03

Creating a Personal Blog & Portfolio

Bringing multiple pages together into one project.

For this assignment, I created a multi-page portfolio with Home, About, and Blog pages. Each page has its own purpose, but they share a common navigation bar and stylesheet to maintain a consistent design.

I practised semantic elements such as <header>, <nav>, <main>, <section>, <article>, and <footer>. I also used ordered and unordered lists, meaningful image descriptions, and relative paths for local illustrations.

Making the website responsive was another key goal. CSS media queries help the layout adapt to smaller screens, so navigation, cards, and text remain usable on mobile devices.

This project helped me understand how individual HTML pages and a shared CSS file can work together to form a complete website.
